# AI Code Parser

AI Code Parser is a VS Code extension designed to apply atomic code operations (such as text replacement, block updates, insertions, deletions, and file creation) directly generated by LLMs via a convenient Webview panel. It includes built-in side-by-side diff previews before any changes are committed to your disk.

## Features

- **JSON Operations Mode:** Easily paste and clean structured JSON payloads from AI.
- **Side-by-Side Diff Preview:** Inspect changes in VS Code's native diff editor before applying them.
- **Safety First:** Prevents path traversal attacks and accidental `.git` modifications.
- **Format on Success:** Automatically triggers your local formatter on modified files.

## How to Use

1. Open a workspace folder (must be a Git repository).
2. Press `Ctrl+Shift+P` (or `Cmd+Shift+P` on macOS) and run the command **AI Code Parser: Open**.
3. Copy the system prompt/instructions from `docs/instruction.txt` and provide it to your AI model so it formats its response correctly.
4. Paste the AI-generated JSON into the extension's text area.
5. Click **Analyze** to see what will change, **Preview** to view a visual diff, and **Apply** to write changes to your codebase.
